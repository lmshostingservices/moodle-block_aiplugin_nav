# AI Dashboard Quick Links

A free Moodle dashboard block for discovering, opening, documenting, checking and
updating the LMS Labs plugin suite from one place.

## Highlights

- Detects installed LMS Labs plugins and groups them by purpose.
- Links directly to plugin settings, reports and public documentation.
- Checks installed versions against the LMS Labs release service.
- Supports individual updates and Update All, with testing releases excluded.
- Displays the site's shared LMS Labs AI-credit balance.
- Uses the active Moodle theme colour and supports narrow dashboard regions.

Quick Links itself is free and consumes no AI credits. AI credits are shared by
the AI-powered plugins connected to the same LMS Labs Site ID.

## Requirements

- Moodle 4.0 to 5.1
- Outbound HTTPS access for version checks, downloads and credit lookups
- Site-administrator access for plugin installation and updates

## Installation

1. Install the ZIP through **Site administration > Plugins > Install plugins**.
2. Complete the Moodle upgrade.
3. Open a dashboard, turn editing on and add **AI Dashboard Quick Links**.
4. For the best suite experience, also install
   [AI Grader Central Config](https://lms-labs.com/docs/ai-central-config).
